<h2>RosJavaLite Message Bindings</h2>
Necessary classes to support message bus data transfer in the RosJavaLite system. These classes are
utilized by the user to be populated with data and transferred via publisher/subscriber channels. They
are tested under JDK25 on Win64, Linux X86 64, and Linux ARM 64 aarch64. They provide JSON bindings to support
LLM core processes etc.
